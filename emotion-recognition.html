Real-Time Facial Emotion Recognition

Le Wagon Bootcamp Project · Nov – Dec 2022

GitHub
Python · TensorFlow · Transfer Learning · OpenCV · Flask

AIdentify is a real-time facial emotion recognition system built in under two weeks as the final project for the Le Wagon Data Science Bootcamp in Zurich. The system detects faces in live webcam video and classifies the expressed emotion across eight categories — neutral, happy, sad, surprised, fearful, angry, disgust, and contempt — using a DenseNet169 model fine-tuned via transfer learning. It was built by a team of three and presented at Le Wagon Demo Day in December 2022.

The model was trained on a combined dataset of approximately 40,000 labelled facial images (FER+ and AffectNet-HQ), achieving 81% accuracy after two-stage fine-tuning. For comparison, a custom CNN trained from scratch reached 71%. The inference pipeline runs OpenCV face detection feeding into a FastAPI prediction endpoint, with the annotated video stream rendered live through a Flask web app.

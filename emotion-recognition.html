Real-Time Facial Emotion Recognition

Le Wagon Bootcamp Project · Nov – Dec 2022

GitHub
Python · TensorFlow · Transfer Learning · OpenCV · Flask · FastAPI

Overview

AIdentify is a real-time facial emotion recognition system built in under two weeks as the final project for the Le Wagon Data Science Bootcamp in Zurich. The system detects faces in live webcam video and classifies the expressed emotion across eight categories: neutral, happy, sad, surprised, fearful, angry, disgust, and contempt. It was presented at Le Wagon Demo Day in December 2022.

The project was built by a team of three: Louis Arts, Alba Gutierrez Pedemonte, and Patrick Hofbauer. Target applications include measuring audience reactions to digital content, improving eLearning feedback loops, and real-time user experience research.

Data

The model was trained on two combined datasets:

  • FER+ — an extended version of FER-2013 containing approximately 30,000 grayscale 48×48 pixel images, labelled across eight emotion categories by crowdsourced annotators.
  • AffectNet-HQ — approximately 31,000 candid facial images collected from internet searches using emotion-related keywords, representing emotions in varied real-world conditions.

After cleaning (removing mislabelled and non-face images), all images were processed through Haar Cascade face detection, resized to 200×200 pixels, converted to grayscale, and normalised by dividing pixel values by 255. Underrepresented emotion classes were augmented through mirroring and rotation to balance the training distribution.

Models

Two architectures were trained and compared:

  • Custom CNN — a convolutional network trained from scratch, achieving 71% accuracy.
  • DenseNet169 (transfer learning) — pre-trained ImageNet weights with the classification head trained first, then all layers unfrozen and fine-tuned end-to-end with a small learning rate, achieving 81% accuracy.

The transfer learning approach substantially outperformed the custom CNN, benefiting from rich feature representations learned on large-scale image data and requiring far fewer samples to generalise well on the target distribution.

System Architecture

The inference pipeline runs as follows: OpenCV captures frames from the webcam and Haar Cascade classifiers detect and crop face regions. Each face crop is passed to the DenseNet169 classifier served via a FastAPI endpoint. The annotated video stream — with predicted emotion labels overlaid — is rendered through a Flask application accessible in the browser.

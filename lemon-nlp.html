LLM Noise Injection Pipeline

Applied NLP Internship · LemonAI, London · Jan – May 2025

Python · Claude API · NLP · Data Engineering

NLP models trained on clean transcripts often degrade in production because real speech output is full of noise that doesn't appear in training data — filled pauses, repetitions, phonetic substitutions, and disfluencies. This internship project at LemonAI addressed that gap by building a pipeline to inject realistic linguistic noise into clean transcription data, expanding training distributions without requiring additional labelled examples.

The pipeline combines two components: a rule-based module for deterministic, high-volume noise injection based on a taxonomy of patterns identified through corpus analysis, and an LLM component using the Claude API for generative noise that produces naturalistic, contextually coherent variation — the kind of disfluency that rules alone can't replicate. Downstream NLP models trained on the augmented data showed improved robustness to real-world transcription noise.
